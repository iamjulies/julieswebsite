## 🌐 Hướng Dẫn Triển Khai Lên GitHub Pages / Tên Miền Riêng (`iamjulies.me`)

1. Tạo repository mới trên GitHub (ví dụ: `iamjulies.github.io`).
2. Đẩy toàn bộ mã nguồn trong thư mục này lên GitHub:
   ```bash
   git init
   git add .
   git commit -m "feat: release julies personal website v1.0.0"
   git branch -M main
   git remote add origin https://github.com/iamjulies/iamjulies.github.io.git
   git push -u origin main
   ```
3. Vào mục **Settings -> Pages** trong GitHub Repository, chọn nhánh `main` và thư mục `/ (root)`.
4. Trang web sẽ ngay lập tức hoạt động tại địa chỉ: `https://iamjulies.github.io/` hoặc gắn domain riêng `iamjulies.me`.
